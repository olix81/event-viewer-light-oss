MQTT Event Viewer si sottoscrive a un topic MQTT, conserva gli eventi ricevuti (in memoria e, opzionalmente, in SQLite) e li espone via HTTP. Questa pagina descrive le API che una interfaccia web può usare.

Formato di un evento

Ogni messaggio MQTT viene salvato come oggetto JSON. Se il payload è JSON valido, i suoi campi noti vengono copiati in event_data; altrimenti event_data è assente. 

{
  "timestamp": "2026-03-15T10:42:07Z",
  "event_data": {
    "src": "master",
    "id": 102,
    "type": "FMEAS",
    "desc": "fine test",
    "timestamp": 1718030010,
    "timestamp_iso": "2024-06-10T14:33:30Z",
    "rule": null,
    "anc": null,
    "meas": [ { "amp": 1, "status": 0, "v_open": 34.5, "zones": [ ... ] } ]
  }
}
CampoDescrizione
timestampIstante di ricezione da parte del viewer (ISO 8601).
event_data.srcSorgente dell'evento (stringa).
event_data.idIdentificativo numerico assegnato dal mittente.
event_data.typeTipo di evento (es. LSTART, FMEAS).
event_data.descDescrizione leggibile.
event_data.timestampTimestamp Unix inviato dal mittente; timestamp_iso è la sua forma ISO.
event_data.rule, anc, measBlocchi strutturati copiati così come arrivano (oggetti, array o null).

Endpoint HTTP

Tutte le risposte API sono application/json.

EndpointDescrizione
GET /File statici serviti dalla cartella web/ accanto all'eseguibile.
GET /api/infoVersione e configurazione: {"version":"0.2.0","mqtt":{"host":"…","port":1883,"topic":"…"},"buffer_limit":8192}
GET /api/statusStato MQTT: {"connected":true,"last_connected":"…","last_error":""}
GET /api/eventsCronologia paginata, dal più recente (vedi sotto).
GET /api/events/allTutta la cronologia, dal più recente: {"events":[…],"total":N}. Può essere pesante: preferire /api/events.
GET /streamServer-Sent Events con gli eventi live.

Paginazione di /api/events

per_page vale 20 di default, massimo 50. Il formato dipende dalla persistenza.

Con SQLite attivo (keyset)

ParametroSignificato
before_idEventi più vecchi di questo id (pagina successiva).
after_idEventi più recenti di questo id (pagina precedente). Ignorato se c'è before_id.
from_ts, to_tsFiltro temporale (timestamp Unix, secondi).
 
{"events":[…],"per_page":20,"has_newer":false,"has_older":true,
 "first_id":123,"last_id":104,"prev_after_id":0,"next_before_id":104,"total":999}

Pagina più vecchia: ?before_id=<next_before_id> (se has_older). Pagina più recente: ?after_id=<prev_after_id> (se has_newer).

Senza SQLite (buffer in memoria)

Parametro page (da 1). Risposta: {"events":[…],"page":1,"per_page":20,"total":N}.

Un client che vuole funzionare in entrambi i casi può controllare se la risposta contiene next_before_id o page.

Stream live (SSE)

const source = new EventSource("/stream");
source.onmessage = (msg) => {
  const evt = JSON.parse(msg.data);   // stesso formato di /api/events
  console.log(evt.event_data?.type, evt.event_data?.desc);
};
  • Ogni evento arriva come messaggio data: con il JSON dell'evento.
  • Appena connesso, il client riceve fino a SSE_CACHE_LIMIT eventi già in memoria, dal più vecchio al più recente: se carichi anche la cronologia, deduplica.
  • Parametro replay: /stream?replay=0 salta il reinvio (consigliato se carichi la cronologia da /api/events); ?replay=N lo limita a N eventi, sempre entro SSE_CACHE_LIMIT.
  • Il server invia periodicamente commenti : keepalive; EventSource si riconnette da solo se la connessione cade.

Scrivere la propria interfaccia

  • Il server serve qualunque file presente in web/: sostituisci il contenuto della cartella con la tua UI. index.html è la pagina iniziale.
  • Le pagine sono servite con una Content-Security-Policy restrittiva (default-src 'self'; script-src 'self'; style-src 'self'): niente script o stili inline, niente CDN. Metti JS e CSS in file separati dentro web/.
  • Gli header CORS sono disabilitati: la UI deve essere servita dallo stesso server (o dietro lo stesso reverse proxy) delle API.
  • Licenze: il server è GPL-2.0-only; questa interfaccia d'esempio è MIT. Una UI che comunica col server solo via HTTP/JSON è un programma separato e può avere la licenza che preferisci.
